# SQL
An introduction the SQL Programming Language

## History
  # SQL's Origin?
  SQL stands for Structured Query Language. Back in the 1970s, scientists at the International Business Machines Corporation (IBM) were trying to create a programming language to make it easier to interact with the data stored in IBM's System R database. Finally, scientists Donald Chamberlin and Raymond Boyce created SQL at the San Jose Research Laboratory. A commercial version of SQL became available to the public in 1979.

  # What is SQL used for?
  SQL is primarily used for relational database management systems. It is the standard language used to store, access, and manipulate the data in your company's database. It's used in practically every field since every company needs an easy way to store and retrieve large amounts of information. For example, many hospitals have patient information in a database and use SQL to retrieve and update it during a visit.
